## 🚀 Installation

---
Since this is a frontend project, no backend server or database is required.

### 1. Clone the repository

```bash
git clone https://github.com/AnkitaSanjayJadhaw/E-Course-Website-Template
```

### 2. Open the project

```bash
cd E-Course-Website-Template
```

### 3. Run the website

You can simply open:

```text
index.html
```

in your browser.

Alternatively, you can use **VS Code Live Server** for a better development experience.

## 💡 How It Works

---
The website uses a multi-page structure where each major section has its own HTML page.

The main navigation connects:

```text
Home
  │
  ├── About Us
  │
  ├── Courses
  │     ├── Web Development
  │     ├── SEO
  │     ├── Digital Marketing
  │     ├── App Design
  │     ├── Game Design
  │     ├── Graphic Designing
  │     └── Interior Designing
  │
  ├── Teachers
  │
  ├── Contact
  │
  └── Join Now
```

The website is designed so that it can later be extended with backend functionality such as user registration, course enrollment management, authentication, databases and online payments.
